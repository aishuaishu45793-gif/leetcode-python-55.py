## 💻 Sample Python Program

### Find the Sum of Numbers in a List

```python
numbers = [10, 20, 30, 40, 50]

total = sum(numbers)

print("Numbers:", numbers)
print("Sum:", total)
```

**Output:**

```text
Numbers: [10, 20, 30, 40, 50]
Sum: 150
```
